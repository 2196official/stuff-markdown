# Changelog

Changes to the Stuff Markdown specification and to the packages in this repository. The spec's version is the number in the version marker; the packages use their own semantic versions.

## October 31, 2026

### Specification 1

- The first version: English labels, ISO dates and times, status checkboxes, dependencies, Plans, Someday, Deadlines, Tags, repeats, quoted Notes, escaping, extensions, and the version marker.

### Packages 0.1.0

- Swift reference implementation (`StuffMarkdown` library) that parses any text to a document and writes documents back.
- JavaScript/TypeScript implementation with the same behavior.
- Shared test suite of 40 cases that both pass.
